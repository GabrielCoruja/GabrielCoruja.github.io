# 🐓 Galo Forte e Vingador

Minha primeira página: uma **página de fã do Clube Atlético Mineiro**, feita **só com HTML e CSS**, sem nenhuma linha de JavaScript.

**🔗 Ver online:** https://gabrielcoruja.github.io/projetos/projetos-html-css/html-css/

## O que tem na página

- Cabeçalho com **listras preto e branco** feitas com `repeating-linear-gradient` e um menu fixo no topo.
- **História** do escudo e do mascote em cartões.
- **Títulos** em cartões que reagem ao passar o mouse.
- **Jogadores** numerados automaticamente com **contadores CSS** (`counter-increment`).
- **Curiosidades** em sanfona com `<details>` e `<summary>`, sem JavaScript.
- Rolagem suave entre as seções e layout que se adapta ao celular.

## Histórico

Projeto de 2019, meu primeiro com HTML e CSS na Trybe. A primeira versão usava imagens de outros sites (o escudo e o mascote), que hoje não carregam mais. Esta versão usa só HTML e CSS e não reproduz o escudo oficial do clube. Os títulos e o elenco são os de 2019, quando a página foi criada.

> Página de fã, sem relação oficial com o Clube Atlético Mineiro.

## Como executar

Abra o `html-css/index.html` no navegador.
