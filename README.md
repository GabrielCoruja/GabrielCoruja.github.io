# 🦉 gabrielcoruja.github.io

Meu portfólio pessoal, publicado pelo GitHub Pages em **https://gabrielcoruja.github.io/**.

Feito à mão com **HTML, CSS e JavaScript puro**, sem frameworks e sem etapa de build. Tem tema claro e escuro (segue o sistema e pode ser trocado no botão), layout responsivo e cuidados de acessibilidade.

## Como executar localmente

Qualquer servidor estático funciona. Por exemplo:

```sh
python3 -m http.server 8000
```

Depois abra http://localhost:8000.
